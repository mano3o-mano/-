# 메가죽림고수협객온라인

대나무 숲에서 쏟아지는 화살을 친구들과 같이 피하는 웹 게임. 인원 제한 없음.

- 한 명이 **새 방 만들기** → 4자리 코드를 친구들에게 알려주기
- 친구들은 같은 주소로 들어와서 이름 + 코드 입력 → **준비**
- 모두 준비되면 방장이 시작

놀이 방식: 보통 / 흉악(패 2~3장) / 랜덤(판 중간에 새 패) / 커스텀(쓸 패·판당 패 수·화살 세기·득도 시간)
규칙 카드(패) 16장: 평온 질풍 폭우 십자포화 짙은안개 거꾸로 빙판 콩알 거구 달밤 회오리 완급 복병 경공 분신 협곡

방장 브라우저가 중계 서버 역할을 합니다 (PeerJS, 별도 서버 필요 없음).
방장이 나가면 방이 닫힙니다.

배경음악: Where the Bamboo Bends, Final Strike at Dawn (설정에서 선택)
